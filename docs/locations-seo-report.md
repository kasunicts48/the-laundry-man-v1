## How links are structured

### Locations page (directory)

```
/locations.html#<section-id>                    → scrolls to a keyword/service section
/locations.html#<section-id>/<region-id>         → scrolls to a region within that section
```

**Examples:**

- `/locations.html#laundry-near-me` — Laundry Near Me section  
- `/locations.html#curtain-cleaning/bedfordshire` — Curtain Cleaning → Bedfordshire  
- `/locations.html#dry-cleaning/manchester` — Dry Cleaning → Manchester  

### Local landing pages (individual areas)

Each neighbourhood link goes to a URL slug based on the area name:

```
/<area-slug>
```

**Examples:** `/manchester`, `/didsbury`, `/leeds`, `/aley-green`

Region headings link to the main city/county slug (e.g. Bedfordshire → `/bedfordshire`, Manchester → `/manchester`).
